Personalize pelo link (todos opcionais):

`https://adauctojr.github.io/feliz-aniversario/?nome=Rafael&idade=30&de=Adaucto&tel=5511999999999`

- `nome` – nome do aniversariante
- `idade` – idade
- `de` – quem enviou (assina a última cartinha)
- `tel` – seu WhatsApp com DDI+DDD, para o botão "Responder" abrir a conversa com você
